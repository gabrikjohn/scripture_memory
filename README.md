# Scripture Memory Codex — Masterwork Edition

A private, offline-first Scripture memory PWA with a guided Romans 1 mastery
path, spaced review, active-recall drills, and a fully art-directed illuminated
manuscript interface.

## Run locally

Serve the repository over HTTP, then open `index.html`. The app stores progress
on the current device and works offline after the first successful load.

## Privacy and text rights

Do not publish or redistribute.

## Artwork

The decorative hero, scriptorium, folio, medallion, and icon assets were created
specifically for this app. Interface copy remains live HTML for accessibility,
responsive layout, and high-contrast reading.
