ROMANS 1 LEARNING PATH
- Seven thought-units based on the chapter's argument
- Smaller segments within the longer units
- Thought-unit recitations that integrate the segments
- Three cumulative bridges: Romans 1:1–15, 1:16–23, and 1:24–32
- Whole-chapter recitation challenge
- Sequential unlocking after successful active recall
- Five recall levels: Read, Fill Blanks, First Letters, Type, Recite
- Advanced random-entry and transition drills
- Error-repair cloze drills based on words missed while typing
- Spaced review and durable-mastery tracking

FASTEST WAY TO TEST ON A COMPUTER
1. Extract the ZIP.
2. Double-click index.html.
3. Begin with Romans 1:1–2 on the Today screen.

PWA / IPHONE INSTALLATION
A service worker requires HTTPS (or localhost), not a file:// URL.
Host this folder only in a private HTTPS location that is inaccessible to third parties, or run a local server for testing.
Then open the private site in Safari and choose Share > Add to Home Screen.

SIMPLE LOCAL TEST SERVER
From the extracted folder, run one of these commands:
- Python: python3 -m http.server 8080
- Node: npx serve
Then open http://localhost:8080 on the same computer.

BACKUPS
Use Settings > Export backup before clearing browser data or moving to another device.
